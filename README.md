# Plate Pal MVP

Plate Pal is a lightweight concierge-style MVP for testing whether college students and recent graduates want social meal inspiration from peers.

## Core hypothesis
At least 40% of target users who visit the MVP will complete at least one core action:
- open a recipe
- save a meal
- join a community
- share a meal

## Precommitted decision rule
If at least 40% of 10+ target users complete one or more core actions, continue developing the social meal-discovery concept.
If fewer than 40% do so, revise the value proposition or primary user flow before adding premium grocery features.

## How to run
Open `index.html` in a browser, or publish through GitHub Pages.

## Data
The MVP logs interactions in browser localStorage.
Use "Export Test Data" in the footer to download the event log for your user-test evidence.

Important: Each tester should use their own browser/device or an incognito session so your denominator stays clean.
